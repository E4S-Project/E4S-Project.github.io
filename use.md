Once E4S is installed, there are several ways to explore, verify, and get support for your deployment. Below is an overview of what's available. Additional documentation is available from the side menu.

|Use Option | Description |
|-----------|-------------|
| E4S Guide Bot | Get instant, AI-powered answers about E4S products, installation, and usage patterns. See [E4S Guide Bot](/guide-e4s-bot/). |
| Documentation | Browse detailed technical documentation for E4S products and workflows. See [E4S Documentation](/documentation/). |
| Product Catalog | Search and browse the full E4S product catalog, including package details and versions. See [E4S Product Catalog](/product-catalog/). |
| Test with E4S | E4S can be used for upstream or downstream testing of your own software products. For example, if you produce compilers or tools for HPC-AI users, E4S can be a reasonable proxy for the HPC-AI user community. See [Test with E4S](/test-with-e4s/) for more details. |
| Facility Demos | See E4S running in practice on production HPC systems. See the [Frontier E4S Container Demo](/frontier-container-demo/). |
| Cluster-Specific Instructions | Follow platform-specific guidance for running E4S on particular clusters. See [Frank Cluster Instructions](/frank-cluster-instructions/). |
